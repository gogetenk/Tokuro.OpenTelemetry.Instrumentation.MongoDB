# OTel DB semantic-convention mapping

This library dual-writes the OpenTelemetry **legacy** and **stable** database semantic conventions during the migration window. Both attribute sets are emitted by default; either can be disabled via `EmitLegacyAttributes` / `EmitStableAttributes`.

Reference specifications:

- Stable DB conventions: <https://opentelemetry.io/docs/specs/semconv/database/database-spans/>
- Legacy DB conventions (historical): <https://github.com/open-telemetry/semantic-conventions/tree/main/docs/database>

## Attributes actually emitted

The table below enumerates every tag that `MongoCommandTelemetry` sets on a span. Anything not in this table is not emitted by this library.

| Attribute            | Kind                                       | When emitted                                                              | Value source                                                                                                                                                          | Reference                                                                                                                                  |
| -------------------- | ------------------------------------------ | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `span.type`          | Vendor compatibility                       | Every sampled-in span                                                     | Constant `"mongodb"`.                                                                                                                                                 | DD compatibility — DataDog database service splitting.                                                                                     |
| `db.operation.name`  | Stable                                     | Every sampled-in span                                                     | `CommandStartedEvent.CommandName` (e.g. `find`, `insert`, `aggregate`, `update`, `getMore`).                                                                          | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/db/#db-operation-name>                                                    |
| `db.system`          | Legacy (gated on `EmitLegacyAttributes`)   | Every sampled-in span                                                     | Constant `"mongodb"`.                                                                                                                                                 | <https://github.com/open-telemetry/semantic-conventions/blob/main/docs/database/database-spans.md>                                         |
| `db.name`            | Legacy (gated on `EmitLegacyAttributes`)   | Every sampled-in span                                                     | `CommandStartedEvent.DatabaseNamespace.DatabaseName`.                                                                                                                 | <https://github.com/open-telemetry/semantic-conventions/blob/main/docs/database/database-spans.md>                                         |
| `db.statement`       | Legacy (gated on `EmitLegacyAttributes`)   | When `CaptureCommandText = true`                                          | Full command document after BSON tree-walk redaction; truncated to `MaxCommandTextLength` with suffix `...[truncated]`.                                              | <https://github.com/open-telemetry/semantic-conventions/blob/main/docs/database/database-spans.md>                                         |
| `db.system.name`     | Stable (gated on `EmitStableAttributes`)   | Every sampled-in span                                                     | Constant `"mongodb"`.                                                                                                                                                 | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/db/#db-system-name>                                                       |
| `db.namespace`       | Stable (gated on `EmitStableAttributes`)   | Every sampled-in span                                                     | `CommandStartedEvent.DatabaseNamespace.DatabaseName`.                                                                                                                 | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/db/#db-namespace>                                                         |
| `db.query.text`      | Stable (gated on `EmitStableAttributes`)   | When `CaptureCommandText = true`                                          | Same redacted, truncated value as `db.statement` — byte-equal, not re-redacted.                                                                                       | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/db/#db-query-text>                                                        |
| `db.collection.name` | Stable                                     | When the command targets a collection (first string field matching the command name) | `CommandStartedEvent.Command[commandName].AsString`.                                                                                                       | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/db/#db-collection-name>                                                   |
| `server.address`     | Stable                                     | When the driver surfaces a `DnsEndPoint` or `IPEndPoint`                  | `DnsEndPoint.Host` or `IPEndPoint.Address.ToString()`.                                                                                                                | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/server/#server-address>                                                   |
| `server.port`        | Stable                                     | When the driver surfaces a `DnsEndPoint` or `IPEndPoint`                  | `Endpoint.Port`.                                                                                                                                                      | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/server/#server-port>                                                      |
| `error.type`         | Stable                                     | On `CommandFailedEvent`                                                   | `CommandFailedEvent.Failure.GetType().FullName`.                                                                                                                      | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/error/#error-type>                                                        |
| `exception.message`  | Standard (suppressed by default)           | On `CommandFailedEvent` **only when `SuppressExceptionMessage = false`**  | `CommandFailedEvent.Failure.Message`. Driver exceptions echo BSON fragments (E11000 conflicting doc, schema-validation payload, bulk-write rejects) — keep suppressed unless you have a controlled threat model. | <https://opentelemetry.io/docs/specs/semconv/attributes-registry/exception/#exception-message> |

Span status:

- `CommandSucceededEvent` → `ActivityStatusCode.Ok`.
- `CommandFailedEvent` → `ActivityStatusCode.Error` (plus `error.type`, plus the optional `exception.message`).

## Notes

- The `db.collection.name` extraction is opportunistic: it reads the top-level BSON field whose key equals the command name (e.g. `find`, `insert`, `aggregate`). Administrative commands such as `ping`/`hello`/`buildInfo` are filtered out before a span is started — see `MongoCommandTelemetry._ignoredCommands` — so the attribute is simply absent on commands that have no natural collection target.
- For `getMore`, the originating collection is not extracted; `db.collection.name` is omitted.
- The legacy `db.statement` and stable `db.query.text` carry identical content when both are enabled.
- `exception.stacktrace`, `network.transport`, `net.peer.name`, `net.peer.port`, `db.operation` (legacy), and `db.mongodb.collection` are **not emitted** by this library. If you need them, wire a custom OTel processor.
