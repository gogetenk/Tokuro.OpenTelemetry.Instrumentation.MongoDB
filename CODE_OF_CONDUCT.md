# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in full. The canonical text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md>

## Scope

This Code applies in all project spaces — the GitHub repository (issues, PRs, discussions, code review), any community channels operated by maintainers, and public spaces when an individual is representing the project.

## Reporting

Code of Conduct concerns are reported through GitHub **private security advisories** on this repository, with the advisory body tagged `conduct` in the first line. This routes the report to maintainers only and keeps the conversation confidential.

Maintainers will acknowledge receipt within 7 days and communicate the resolution privately to the reporter once the matter is closed.

## Enforcement

Maintainers follow the [Contributor Covenant Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) for the four-tier response ladder (correction, warning, temporary ban, permanent ban).
